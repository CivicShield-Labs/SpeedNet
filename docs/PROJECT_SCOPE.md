# Project Scope

## Purpose

Privacy-conscious automated speed enforcement and average-speed corridor platform.

## Current Phase

Software architecture, simulation, research, and controlled development.

## Out of Scope

- Unauthorized access to vehicles, networks, devices, or government systems
- Bypassing warrants or other legal authorization
- Autonomous consequential enforcement decisions
- Deployment against the public without authorization
- Secret surveillance capabilities
- Unsafe remote control of safety-critical systems

## Design Direction

Systems should prefer:

AI analysis -> human authorization -> constrained system action -> immutable audit evidence
